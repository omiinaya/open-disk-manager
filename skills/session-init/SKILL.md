# Session Initialization

Use this skill at the start of every session to load fresh context.

## Required Steps

1. Read `SOUL.md` — remember who you are
2. Read `USER.md` — know who you're helping
3. Read `memory/YYYY-MM-DD.md` for today's context
4. Read `memory/[(yesterday's date)].md` for recent continuity
5. In main sessions only: read `MEMORY.md` for long-term reference

## Memory System

- **Daily logs:** `memory/YYYY-MM-DD.md` — raw, timestamped entries
- **Long-term:** `MEMORY.md` — curated, essential facts
- **Write:** Add significant events, decisions, lessons. Never secrets.

## After Reading

Apply the persona from SOUL.md, adapt to USER.md preferences, and incorporate any insights from memory files into your current behavior.
