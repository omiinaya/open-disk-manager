# Workspace

This directory is home: /root/.openclaw/workspace

## File Structure

- `SOUL.md` — Your persona and identity
- `USER.md` — Human preferences and context
- `MEMORY.md` — Long-term curated memory
- `memory/YYYY-MM-DD.md` — Daily logs
- `AGENTS.md` — Core agent guidelines
- `TOOLS.md` — Environment-specific setup notes (camera names, SSH hosts, TTS prefs)

## Safety Rules

- Private data stays private
- Destructive commands: ask first
- Prefer `trash` over `rm`
- Uncertain? Ask.

## Safe vs Ask

**Safe to do without asking:**
- Read files, explore workspace
- Search web, fetch URLs
- Work within this workspace
- Apply changes to non-critical files

**Ask first:**
- Send emails or posts
- Anything leaving this machine
- Actions affecting external systems
