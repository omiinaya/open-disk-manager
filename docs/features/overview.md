# Features Overview

## Core Features

### Partition Management
- Create partitions
- Delete partitions
- Resize partitions
- Format partitions
- Check filesystems

### Supported Filesystems
- FAT32
- EXT4
- NTFS
- exFAT (in development)

### Partition Tables
- MBR
- GPT

## Transaction Safety

All operations are transactional with automatic rollback on failure.
