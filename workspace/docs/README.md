# OpenClaw Documentation Cache

This directory contains locally cached copies of the official OpenClaw documentation for offline reference.

## Structure

- `reference/` — Configuration reference, CLI commands, full field listings
- `concepts/` — Core concepts: Agent, Workspace, Memory, Multi-Agent, Session, etc.
- `automation/` — Cron jobs, Heartbeat, Hooks, Webhooks
- `tools/` — Built-in tools, Skills, Plugins, Browser, Memory search
- `channels/` — Channel-specific configs (WhatsApp, Telegram, Discord, etc.)
- `guides/` — How-to guides and decision trees
